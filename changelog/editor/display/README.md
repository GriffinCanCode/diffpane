# Editor display

These changes cover the file viewer, visual comparison controls, supported preview formats and appearance settings.

- [Full-file Git markers](06-full-file-git-markers.changed). Show working-tree changes in the gutter and overview.
- [Whole-file comparison](08-whole-file-comparison.changed). Toggle before-and-after views from a Git marker.
- [Text and media previews](10-text-and-media-previews.added). Decode text and present media or hexadecimal previews.
- [Appearance settings](appearance-settings.added). Choose theme, diff layout and editor typography.
